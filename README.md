# STA-145-Final-Project
My repilication package for my STA-145 final project where I analyzed the target age demographic for a sample of netflix shows and looked to see if the target age demographic affected the number of episodes in a show.  
## **Instructions**
To access and utilize the script, open the "burgesd3-final_project" file, which contains the code for my project. To access the dataset, open the "Danielle Burgess - tv shows - Data Table Tabular.csv" file.  
## **Data**
The data used for this analysis was gathering a sample of all netflix shows.  The question being asked was if shows made for children have more episodes on average than shows made for young adults and adults.  Each unit of analysis was one show and 179 observations were collected.  The type of sampling strategy that was used was a simple random sample. 
## **Operationalization**
The concept of target age range the show was made for was operationalized by using a qualitative coding scheme from 1-3 age ranges.  1 would describe a show with a target age demographic of children.  2 would describe a show with a target age demographic of young adults.  And 3 describes shows with a target age demographic of adults.  

The concept of number of episodes in a particular show was operationalized through a quantitative variable named episodes.
